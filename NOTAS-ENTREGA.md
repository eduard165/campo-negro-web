# Campo Negro — primera integración del diseño final

Esta entrega integra las **10 pantallas nuevas** para escritorio y móvil, con imágenes optimizadas WebP y navegación funcional.

## Importante
Esta es una **primera versión visual para revisión**: los textos y composiciones del diseño se encuentran incrustados en las láminas suministradas por el cliente. **Aún no están reconstruidos como HTML editable**. Para el ajuste posterior, sustituiremos cada lámina por fondos e ilustraciones independientes y texto HTML con Gill Sans, Myriad Pro y Luxurious Script.

Los originales están en los ZIP del cliente; las versiones WebP optimizadas se encuentran en `public/imagenes/diseno-final/`.

Ejecutar `npm install` y `npm run dev`. El proyecto original se conserva en los demás componentes; `src/app/page.tsx` presenta las nuevas láminas.
